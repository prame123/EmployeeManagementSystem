# Employee Management System

## Project Overview

Employee Management System is a web-based application developed using **Spring MVC** to manage employee information and perform basic employee-related operations.

The application uses JavaScript for browser-side functionality and interaction with the web pages.

## Technologies Used

* Java
* Spring MVC
* HTML
* CSS
* JavaScript
* Database
* Maven

## Key Features

* Employee information management
* Add and manage employee records
* CRUD operations
* Server-side processing using Spring MVC
* Browser-side functionality using JavaScript
* Database integration

## Architecture

The application follows the Spring MVC architecture:

```text
Browser
   ↓
JavaScript / HTML / CSS
   ↓
Spring MVC Controller
   ↓
Service Layer
   ↓
DAO / Repository
   ↓
Database
```

## How to Run

1. Clone the repository.
2. Import the project into Eclipse or another Java IDE.
3. Configure the required database settings.
4. Build the project using Maven.
5. Deploy/run the application on the configured server.
6. Open the application in a web browser.
